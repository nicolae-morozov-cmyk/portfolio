# Nicolae Morozov Portfolio

This folder is a staging copy of the current static portfolio website. Upload **the contents of this folder** to the root of your GitHub repository; do not upload this folder as a nested directory. Keep all filenames and directory paths unchanged.

## Included

- Homepage and seven static route entrypoints
- Site JavaScript and CSS
- `PROJECT.md`, `AUDIT.md`, and `ASSET-MAP.md`
- The 58 media files currently referenced by the site (about 263 MB total)

Unused/archive exports, reference screenshots, `.DS_Store` files, and ABC Areal font files are excluded. The site uses Inter from Google Fonts. The Areal font is not included because its repository/server license is unresolved.

## Before making this repository public

A public repository makes its source and media files downloadable. Confirm you have permission to redistribute every included project image and video. No passwords or API keys were found in the project scan.

## Deployment status

This is a source upload package, not a completed GitHub Pages deployment. The site currently uses root-based URLs and is intended for `https://nicolaemorozov.com/`; GitHub Pages settings, custom-domain configuration, route refresh behavior, and final deployment checks remain for Phase 03.
